# Template de Atualização de Status (PT-BR)

Use checkpoints curtos e objetivos.

## Formato
**Checkpoint [HH:MM]**
- Escopo: [o que foi atacado]
- Status: [em andamento | concluído | bloqueado]
- Evidência: [rota/teste/PR/log curto]
- Risco/Bloqueio: [se houver]
- Próximo passo: [ação imediata]

## Exemplo
**Checkpoint 14:20**
- Escopo: validação da rota `/performance`
- Status: concluído
- Evidência: carregamento ok, sem erro no Console
- Risco/Bloqueio: sem bloqueios
- Próximo passo: validar `/optimization/board`
